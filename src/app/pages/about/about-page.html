About this demo

This route is prerendered. Its HTML was produced once, during ng build, and shipped as a static file in dist/browser. In production it is served straight off disk — the renderer never wakes up.

Frozen at build time: {{ generatedAtBuildTime }}

Reload as many times as you like: that timestamp never changes. It belongs to the build, not to your visit. That is precisely the limit of prerendering — and the reason the catalog, with its live price and stock, cannot use it.

The three render modes, side by side

Route Mode When the HTML is created
/ and /product/:id Server On every request
/about Prerender At ng build time
/dashboard Client Never — only in the browser

All three coexist in one application, configured in a single file: app.routes.server.ts. The choice is made per route, not per project.
